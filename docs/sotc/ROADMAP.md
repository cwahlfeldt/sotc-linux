# Roadmap — Shadow of the Colossus PC

Updated with every fix. Legend: ✅ done · 🔧 in progress · ⏳ pending

**Strategy (19 Oct 2026):** integrate and test the community's pull requests and forks instead of
redoing the work. Local branch `comunidade` = `main` (0.57) + integrated PRs. The equivalent fixes I
made in the `sotc` branch are left out when the community already has them (and tested them on
hardware we do not have).
